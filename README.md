**Sobre o repositório:**
- Código de extensão de Google Chrome para acessar jurisprudência de maneira rápida.
- Desenvolvido com auxílio de IA. As ferramentas desenvolvidas com IA podem conter erros. Verifique o código e utilize por sua conta e risco.

**Utilizando no Google Chrome:**
1. Salve todos os arquivos na mesma pasta.
2. Abra o Google Chrome e acesse chrome://extensions.
3. Ative a chave Modo do desenvolvedor no canto superior direito.
4. Clique em Carregar sem compactação e selecione a pasta.
   
**Tribunais:**
- TJRS.
- TRF-4.
- STJ.
- STF.

**Modos de busca:**
- Busca por popup (atalho ALT+J).
- Busca por omnibox (barra do navegador com palavra-chave 'juris').
- Busca por menu de contexto.
